# vibe-re

Reverse-engineering workspace for malware-focused research projects, with a strong emphasis on query-driven analysis workflows using `idasql`.

| Project | Description | Start Here |
|---------|-------------|------------|
| `PoisonPlug_1/` | First analyzed PoisonPlug variant — architecture docs, plugin analysis, and automation scripts | [PoisonPlug_1/README.md](PoisonPlug_1/README.md) |

## Repository Policy

- Public repo content is documentation, scripts, and non-sensitive research metadata.
- Sensitive malware-derived artifacts (full IDA databases, decrypted binaries, equivalent bundles) are not distributed in this public repository.

## Research Use

This repository is intended for defensive security research and education.
